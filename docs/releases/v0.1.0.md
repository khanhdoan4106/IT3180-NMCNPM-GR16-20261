## Kiểm thử

- Mọi Pull Request chạy CI hai job: `build` (`mvn verify`) và `build-mysql`
  (MySQL 8.0, `mvn verify -Pmysql`). Cả hai xanh trên `main` của bản này.
- Kiểm thử tích hợp trên MySQL cho hộ gia đình, nhân khẩu, tạm trú/tạm
  vắng, tài khoản và dữ liệu dùng chung giữa hai máy (AC-071).

## Cài đặt

1. Cài JDK 21, MySQL 8 và IntelliJ IDEA theo [setup.md](../setup.md).
2. Chạy `schema.sql` rồi `seed.sql` (đính kèm bên dưới).
3. Sao chép `config/db.properties.example` thành `config/db.properties`,
   điền tài khoản MySQL.
4. Chạy lớp `com.bluemoon.Launcher`. Tài khoản mẫu: `admin` / `Admin@123`.

Sao lưu và khôi phục CSDL: [backup-restore.md](../backup-restore.md).
